# Used Car Price Prediction and Analysis System

**Course:** HOCO492 — Mini Project: Artificial Intelligence and Machine Learning

A complete, reproducible machine-learning system that predicts a used
car's selling price and provides an interactive analytics dashboard, built
end-to-end on real data — no fabricated metrics, datasets, or results
anywhere in this repository.

## Overview

Given a used car's attributes (brand, age, kilometers driven, fuel type,
transmission, engine, mileage, power, seats, owner history), the system
predicts an estimated selling price and an approximate price range, and
explains the factors driving that estimate. A companion dashboard exposes
the underlying dataset statistics and objective model-comparison results.

## Problem Statement

Used-car pricing is inconsistent and hard to estimate without domain
expertise or comparable listings. This project builds a transparent,
data-driven price estimator using classical supervised regression, plus
the full ML lifecycle needed to trust that estimate: documented
preprocessing, objective model comparison, cross-validation, tuning, and
tested deployment.

## Objectives

- Predict used-car selling price from listed attributes (supervised regression).
- Compare five classical regression algorithms (plus XGBoost) objectively.
- Apply proper preprocessing (leakage-free) and feature engineering.
- Select the final model on held-out test performance, not assumption.
- Deliver an interactive, validated Streamlit application.
- Verify correctness and reliability with an automated test suite.

## Features

- Price prediction form with input validation and human-readable "why"
  factors.
- Empirical (explicitly-labeled, not fabricated) price range based on
  test-set residual quantiles.
- Data Analysis dashboard: dataset statistics, distributions, correlation
  heatmap, price-vs-feature charts.
- Model Performance dashboard: cross-validation and test metrics, RMSE/R²
  comparisons, diagnostic plots (actual vs. predicted, residuals, error
  distribution, feature importance) — all loaded from generated reports,
  nothing hard-coded.

## Architecture

```
User -> Streamlit UI -> Input Validation -> Feature Engineering
     -> Preprocessing Pipeline -> Trained ML Model -> Prediction
     -> Result Visualization
```

Full architecture and layer-by-layer design: `docs/system_design.md`.

## ML Algorithms

Linear Regression, Ridge Regression, Decision Tree, Random Forest,
Gradient Boosting, and XGBoost — compared via 5-fold cross-validation,
with `RandomizedSearchCV` tuning on the two strongest tree-based
candidates. Final model selected objectively by lowest test-set RMSE.

**Actual result from this project's dataset (see `reports/results.md`
for full tables and discussion):** final selected model = **Gradient
Boosting**, test RMSE ≈ ₹151,043, R² ≈ 0.9281, MAPE ≈ 21.28%.

## Dataset

CarDekho used-car listings, `"Car details v3.csv"`
(Kaggle: `nehalbirla/vehicle-dataset-from-cardekho`, scraped from
CarDekho.com listings). 8,128 raw rows, 13 columns:
`name, year, selling_price, km_driven, fuel, seller_type, transmission,
owner, mileage, engine, max_power, torque, seats`.

The dataset is already included at `data/raw/used_cars.csv`. If you need
to replace it with a different/updated version, keep the same filename
and column names, or update `src/config.py::RAW_COLUMN_MAP` to match a
different schema — the rest of the pipeline adapts automatically.

## Installation

```bash
python -m venv .venv
```

Windows (PowerShell / Command Prompt):
```powershell
.venv\Scripts\activate
```

Linux / macOS:
```bash
source .venv/bin/activate
```

Install dependencies:
```bash
pip install -r requirements.txt
```

## Training the Model

The trained model is already included (`models/used_car_price_model.pkl`),
generated from the included dataset. To retrain from scratch (e.g. after
changing the dataset or a src/ module):

```
python -m src.train
```

This regenerates: `models/used_car_price_model.pkl`,
`models/model_metadata.json`, `reports/cv_results.csv`,
`reports/model_comparison.csv`, and the diagnostic plots in
`reports/figures/`. Training takes well under a minute on a typical
laptop.

## Running the Application

```
streamlit run app.py
```

Opens the app at `http://localhost:8501` with five pages: Home, Price
Prediction, Data Analysis, Model Performance, About Project.

## Running the Notebooks

```
jupyter lab notebooks/
```

`01_eda.ipynb`, `02_preprocessing.ipynb`, and `03_model_training.ipynb`
are already executed with real output embedded; re-run them top-to-bottom
any time to regenerate against the current dataset.

## Results

Full metric tables, cross-validation results, overfitting check, and error

## Limitations

Regional (India-only) scope, market/time drift, a dropped `torque`
feature, rare-brand grouping, no vehicle-condition data, and a
non-statistically-calibrated empirical price range. Full list:
`docs/limitations.md`.

## Future Scope

Real-time market data, regional pricing models, calibrated prediction
intervals (conformal prediction), SHAP-based explainability, REST API and
cloud deployment. Full list: `docs/future_scope.md`.
